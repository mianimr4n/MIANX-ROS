# Governance

Repository Governance v1 defines how engineering decisions are made, verified, and released.

---

## Purpose

This directory contains the permanent governance documents for the Telepizza ROS repository.

Governance separates:

- Architecture
- Requirements
- Implementation
- Repository Evidence
- Acceptance
- Release

## Repository Truth

The repository is the authoritative implementation source.

- Architecture defines approved direction.
- Requirements define intended capability.
- Repository evidence defines implemented capability.
- Acceptance defines verified delivery.
- Release records define released capability.

Planning documents are not implementation evidence.

---

## Governance Scope

These documents are permanent engineering governance.

They do not contain:

- sprint plans
- temporary tasks
- implementation prompts
- feature requests
- release notes

Those belong elsewhere in the repository.
