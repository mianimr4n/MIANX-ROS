# Purpose

This document defines the Defense in Depth strategy for protecting enterprise systems through multiple, independent security layers.

No single control should be relied upon as the sole line of defense.

- Multiple Security Layers
- Least Privilege
- Zero Trust
- Continuous Verification
- Secure by Design
