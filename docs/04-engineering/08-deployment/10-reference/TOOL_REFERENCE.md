# 16. Version Management

Every approved tool should

- Use supported releases
- Follow LTS versions where available
- Receive regular updates
- Be security patched
- Be reviewed annually

---

# 17. Governance

Every tool requires

- Technical Approval
- Security Approval
- Documentation
- Ownership
- Review Schedule
- Lifecycle Tracking

---

# 18. Best Practices

- Prefer approved tools.
- Standardize engineering workflows.
- Avoid unnecessary tooling duplication.
- Review tools annually.
- Track tool lifecycle status.
- Automate version compliance where possible.
