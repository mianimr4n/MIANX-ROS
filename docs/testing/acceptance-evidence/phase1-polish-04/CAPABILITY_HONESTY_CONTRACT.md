# POLISH-04 — Capability honesty contract

Vocabulary: `apps/website/client/src/lib/business-admin-capability.ts`

| State | Meaning |
| --- | --- |
| LIVE | Editable / operational capability with verified source |
| PARTIAL_LIVE | Implemented subset; caveats apply |
| FOUNDATION | Structure present; depth incomplete |
| NAVIGATION_ONLY | Link to another Admin workspace — not editable Settings |
| METADATA_ONLY | Status/metadata without credential management |
| CONFIGURATION_REQUIRED | Capability needs setup before use |
| UNAVAILABLE | Source/capability not present |
| DEFERRED | Phase 2+ |

Settings categories use `presentation` separately from legacy `classification`.
