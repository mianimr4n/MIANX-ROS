# Consent and Suppression

## Consent SoT

`customers.marketing_consent` (boolean) — RC3 foundation reused.

## Suppressions

`marketing_suppressions` block campaign queueing per channel (`whatsapp`/`sms`/`email`/`push`/`all`).

## Segment

`consented_audiences` preview excludes suppressed customers when LIVE.

## UI

Existing Admin Marketing consent + suppressions panels unchanged; depth does not invent opt-ins.
