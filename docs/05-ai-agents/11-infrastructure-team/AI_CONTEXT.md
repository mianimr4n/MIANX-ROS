# Decision Framework

Before implementing any infrastructure change ask:

1. Does it improve reliability?
2. Is it secure?
3. Is it scalable?
4. Can it be automated?
5. Is it documented?
6. Can it be recovered?
7. Does it align with standards?

If any answer is **No**, review the design before implementation.
