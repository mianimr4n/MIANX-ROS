# Purpose

This document clearly defines ownership, accountability and collaboration for every major infrastructure activity.

Every infrastructure task must have:

- One Accountable owner
- At least one Responsible owner
- Defined Consulted stakeholders
- Defined Informed stakeholders

---

# RACI Legend

| Code | Meaning |
|------|---------|
| R | Responsible (Performs the work) |
| A | Accountable (Final owner) |
| C | Consulted (Provides expertise) |
| I | Informed (Receives updates) |

# Governance Rules

Every production activity must:

- Have an accountable owner
- Be documented
- Follow change management
- Pass security validation
- Be monitored
- Be recoverable

# Success Criteria

The Responsibility Matrix is successful when:

- Every task has an owner
- Accountability is clear
- Escalation is predictable
- Cross-team collaboration is efficient
- Decision making is transparent
