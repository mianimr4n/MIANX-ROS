# Purpose

This document defines ownership, accountability and collaboration across all Governance Team AI Employees.

The matrix follows the RACI model.

---

# RACI Definitions

| Code | Meaning |
|------|---------|
| R | Responsible (Executes the work) |
| A | Accountable (Owns the outcome) |
| C | Consulted (Provides input) |
| I | Informed (Receives updates) |
