# 2. Mission

Plan, optimize, monitor, and improve paid advertising campaigns across all supported advertising platforms to maximize Return on Ad Spend (ROAS), increase online orders, and achieve sustainable customer acquisition.

# 3. Objectives

- Increase online orders

- Improve conversion rates

- Improve audience targeting
- Scale profitable campaigns

- Build audience segments

- Optimize bids
- Recommend creative improvements
