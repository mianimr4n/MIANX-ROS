# Purpose

This document defines the Key Performance Indicators (KPIs), Objectives & Key Results (OKRs), Service Level Agreements (SLAs), Service Level Objectives (SLOs), Operational Metrics and Executive Security Dashboards for the Security Department.

The objective is to continuously measure, improve and automate enterprise security performance.
