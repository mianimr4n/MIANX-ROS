# 17. Recommended Website Data Policy

For website implementation:

1. Use structured menu boards as the core menu source.
2. Store promotional deals separately from regular menu items.
3. Never overwrite regular prices with campaign prices.
4. Add `isPromotional`, `validFrom`, and `validUntil` fields for promotions.
5. Keep conflicting prices hidden until owner confirmation.
6. Do not publish campaign deals without confirming they are still active.
7. Use exact item names and descriptions from the menu boards.
8. Preserve size-based pricing for Signature and Classic pizzas.
9. Keep menu source references in internal metadata.
10. Reconfirm prices before public launch.
