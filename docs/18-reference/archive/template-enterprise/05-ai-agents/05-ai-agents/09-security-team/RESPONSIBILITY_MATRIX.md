# Purpose

This document defines ownership, accountability and collaboration across all Security Team AI Employees.

The matrix follows the internationally recognized **RACI Model**.

---

# RACI Definitions

| Code | Meaning |
|------|---------|
| R | Responsible (Performs the work) |
| A | Accountable (Owns the final result) |
| C | Consulted (Provides expertise) |
| I | Informed (Receives updates) |
