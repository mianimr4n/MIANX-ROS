# Purpose

This document defines the ownership, accountability and collaboration model for every DevOps function within the Telepizza Platform.

It establishes clear responsibilities using the RACI model:

- **R** = Responsible
- **A** = Accountable
- **C** = Consulted
- **I** = Informed
